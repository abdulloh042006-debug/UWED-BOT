# UWED Talent Network — dizayn prototiplari

Interaktiv prototiplar (Claude Design kanvasi uchun `.dc.html` formati):

- `Main.dc.html` — Mini App (onboarding, matching, skill exchange, kalendar, portfolio, loyihalar)
- `Admin.dc.html` — Admin panel (panel, foydalanuvchilar, tasdiqlash, shikoyatlar, loyihalar, e’lonlar, sozlamalar va audit)
- `canvas.json` — kanvas indeksi

Bu fayllar mustaqil sayt emas: ular `support.js` ish vaqtini talab qiladi va faqat dizayn ma’lumotnomasi hisoblanadi.
Ulardagi raqam va ismlar namuna (DEV) ma’lumotlar, backend javobi emas.
